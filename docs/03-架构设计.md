# 架构设计 — AI Coding

> 单体起步（当前）→ 微服务演进（阶段 6） ｜ 更新：2026-09-15

## 1. 单体架构（阶段 2–5，已实现）

```
Vue 3 前端 ──── HTTP / SSE ────> Spring Boot 单体（:8123 /api）
                                   │
        ┌──────────┬───────────────┼────────────────┐
     controller  core/auth      core/ai           service/impl
   user/app/chat  JWT+拦截器   模型管理/路由/    编排（生成锁、
   /preview                    解析器/工具        对话记忆、SSE 推送）
                                   │
        MySQL 8（业务数据）  Redis（预留缓存）  本地工作区 tmp/workdir/{appId}/（生成产物）
```

### 关键设计

| 模块 | 设计 | 说明 |
| ---- | ---- | ---- |
| AI 模型接入 | 策略模式（AiModelManager） | Mock / DeepSeek 双实现，OpenAI 兼容协议，多模型可扩展 |
| 生成类型路由 | 智能路由 + 兜底规则（CodeGenRouter） | 首次生成时决策 HTML_SINGLE / HTML_MULTI_FILE / VUE_PROJECT，LLM 失败走关键词 |
| 流式生成 | SSE（SseEmitter + 虚拟线程） | 事件：router / delta / tool / done / error / ping，15s 心跳 |
| 单文件生成 | 直出代码流（CodeStreamParser 按行剥围栏） | 代码增量实时推送，结束落盘 index.html |
| 多文件生成 | AiServices + @Tool(writeFile) | 每请求独立工具实例隔离并发，写文件事件实时推送 |
| 对话记忆 | MySQL chat_history 游标分页 | (app_id, create_time) 联合索引；重建上下文取最近 6 条 |
| 并发控制 | 应用级生成锁 | 同一应用同时仅一个生成任务，SSE 完成/超时自动释放 |
| 登录态 | JWT（hutool）| Authorization 头 + `?token=`（EventSource 场景），BCrypt 密码 |
| 预览服务 | PreviewController | 生成站点静态文件按 appId 托管，路径穿越防护 |

## 2. 微服务架构（阶段 6 规划）

```
Vue 3 ──> Gateway(8080, 鉴权/限流/路由)
             ├─> user-service        用户/登录/配额
             ├─> app-service         应用/版本/广场
             ├─> ai-service          LangGraph4j 工作流/多模型路由/计量
             ├─> deploy-service      静态托管/deployKey 分享
             └─> screenshot-service  无头浏览器截图封面
      Dubbo 3 RPC（app→ai→user 鉴权传递）
      Nacos（注册 + 配置中心）  Sentinel（限流熔断）
      多级缓存：Caffeine(本地) → Redis(分布式) → MySQL（广场/模板/用户信息）
      可观测：Micrometer → Prometheus → Grafana
```

### 拆分原则
- 按业务能力垂直拆分，共享代码下沉 common/model 模块
- 服务间调用统一 Dubbo RPC，对外统一走 Gateway
- 生成类长任务（ai-service）与短请求（user/app）隔离部署，避免互相拖垮

## 3. 核心工作流（阶段 3 引入 LangGraph4j）

```
[路由] → [生成] → [质量门禁] --fail--> [自动修复 ≤3 轮] --pass/超限--> [快照/封面]
  │         │           │                                    │
  └─────────┴───── 节点状态实时 SSE 推送到前端时间线 ────────────┘
```

每次生成/修改完成后写入 app_version 版本快照（版本树，支持回滚），模型调用写入 model_invocation 计量。
