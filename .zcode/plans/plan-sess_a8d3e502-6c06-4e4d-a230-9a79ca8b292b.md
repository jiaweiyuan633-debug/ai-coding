# AI Coding — AI 零代码应用生成平台 实施计划（含 Git 推送策略）

## 一、项目定位

以海报技术栈为纲（LangChain4j + LangGraph4j + Spring Cloud Alibaba + Dubbo + Redis/Caffeine 多级缓存 + 响应式编程 + Prometheus + 多租户/设计模式），对标鱼皮 yu-ai-code-mother 但**做差异化创新**。Java 17 + Spring Boot 3.x + Vue 3，大模型用 DeepSeek（OpenAI 兼容接口）。项目命名与远端仓库对齐：`ai-coding`。

## 二、Git 工作流（你新增的要求）

- 阶段 0：工作区 `git init`，关联远端 `https://github.com/jiaweiyuan633-debug/ai-coding.git`（分支 main），配好 .gitignore（Java/Node/IDE，**.env 密钥绝不入库**）
- **增量推送**：完成一小部分（每个功能点/每阶段验收）就 commit + push 到 main，commit 规范：`docs:/feat:/chore:` 前缀
- 认证：Windows Git Credential Manager 首次推送可能弹浏览器登录 GitHub；若推送失败会立即告诉你，需要你登录一次或提供 PAT

## 三、竞品调研结论（阶段 1 落盘为调研报告）

已调研确认、全部吸收的优点：
- **v0.dev**：版本历史/回滚 → 我们的「版本时光机」
- **bolt.new**：错误自动检测→修复循环、token 可视化 → 「质量门禁工作流 + 用量中心」
- **lovable.dev**：选中元素局部修改、模板社区、Remix → 可视化编辑 + 模板/精选广场
- **Dify/扣子**：工作流可观测、多模型切换 → 工作流节点实时可视化 + 多模型路由
- **原项目**：AI 路由决策生成类型、SSE 流式工具调用写文件、游标分页对话历史、deployKey 部署分享

## 四、创新点（差异化核心）

1. **透明工作流**：LangGraph4j 编排「智能路由 → 生成 → 质量门禁（HTML/JS 校验）→ AI 自动修复（≤3 轮）→ 截图封面」，节点状态 SSE 实时推送到前端时间线
2. **版本时光机**：每次对话修改自动生成版本快照树，一键回滚/对比
3. **多模型路由**：策略模式接入多家 OpenAI 兼容模型，DeepSeek 默认
4. **用量中心**：模型调用全量计量（token/耗时/次数），多租户配额
5. **模板广场 + Remix**：精选应用一键复制二次创作

## 五、技术架构

- 单体期：Spring Boot 3.5.x、LangChain4j 1.x（OpenAI 兼容 starter）、LangGraph4j、MyBatis-Plus、MySQL 8、Redis、Caffeine、JWT、SSE 响应式流、Hutool
- 微服务期：Spring Cloud Alibaba（Nacos + Sentinel）、Dubbo 3、Spring Cloud Gateway，拆分 gateway / user / app / ai / deploy / screenshot / common / model 模块（ai-coding-* 命名）
- 前端：Vue 3 + Vite + Pinia + Arco Design Vue，工作台三栏（对话 | 实时预览 | 文件树+版本时光机）
- 部署：Docker Compose 一键全套（MySQL、Redis、后端、Nginx 前端+静态托管、Prometheus + Grafana），生成站点用 deployKey 子域名（本地 `*.localhost` 模拟，预留上云路径）

## 六、数据模型

user（用户/角色/配额）、app（initPrompt/codeGenType/deployKey）、chat_history（游标分页联合索引）、**app_version（版本快照树）**、**workflow_run（工作流节点执行记录）**、**model_invocation（模型计量）**、template（模板）。

## 八、分阶段实施步骤（每阶段完成即推送）

- **阶段 0 环境+仓库**：检查/安装 JDK 17、Maven(mvnw)、Node 20+、Docker Desktop；git init + 关联远端 + 首推 README/docs 骨架
- **阶段 1 文档**：docs/01-项目计划书.md（含竞品调研、架构、里程碑）→ 推送
- **阶段 2 单体核心闭环**：注册/登录 → 应用 CRUD → DeepSeek 接入（AI 客户端抽象 + Mock Provider，无 Key 也能开发）→ AI 路由 → SSE 流式生成（工具调用写文件）→ 对话记忆 → 实时预览 → 推送
- **阶段 3 工作流与创新**：LangGraph4j 质量门禁+自动修复、节点状态推送、版本时光机、多模型路由、模型计量 → 推送
- **阶段 4 部署分享与广场**：一键部署（静态托管+deployKey）、网站截图封面、模板/精选广场、Remix → 推送
- **阶段 5 前端全套**：创作页、三栏工作台、可视化编辑、我的应用、广场、管理端 → 推送
- **阶段 6 微服务化**：拆 gateway/user/app/ai/deploy/screenshot，Nacos+Dubbo+Sentinel，多级缓存，Prometheus+Grafana → 推送
- **阶段 7 上线**：Docker Compose 全套编排、端到端 GUI 冒烟测试、部署手册 → 推送

## 九、验收方式

每阶段停下演示验证后再进入下一阶段；阶段 7 一条 `docker compose up` 起全套，浏览器完整走通「注册→创建→生成→修改→回滚→部署→分享访问」。

## 十、需要你提供的

1. **DeepSeek API Key**（阶段 2 联调时配置到本地 .env，不入库；此前用 Mock 模式开发不受阻）
2. GitHub 推送认证（首次 push 时登录一次即可）
3. 阶段 6 需要本机 16G 内存为宜跑多服务容器（不足则压缩并行度）

风险控制：AI 功能均先抽象接口 + Mock，避免被 Key/网络阻塞；每阶段可运行、可回退、已推送远端。
